## 编辑变化

待办保留 `☐`、`☑` 文本作为状态，界面在标记位置绘制圆角勾选框。完成项的灰色和删除线使用 TextKit 临时属性，保存、普通富文本复制和复制为 Markdown 不会把这条显示用删除线误当作用户设置的格式。旧版便签无需转换。

长待办使用悬挂缩进，换行与文字对齐。点击方框保留原来的选区和输入位置。`- [] `、`- [ ] `、`- [x] `、`* [] `、`+ [] `、`[ ] ` 和 `[x] ` 可在行首输入，最后的空格触发转换。清单内 Tab 缩进，ShiftTab 退一级；回车续项，空子项回车退一级，空根项回车退出。

`> ` 在输入时转换成带侧边线的引用。回车续写，空引用回车退出。粘贴 Markdown 支持嵌套引用。复制为 Markdown 时，引用与后面的正文之间会补空行，防止正文被算进引用。

普通复制的 HTML 补上待办状态、引用、等宽文字和删除线，普通嵌套列表使用父子列表结构。复制为 Markdown 将子列表按四个空格输出，避免编号列表下的子任务丢失层级。代码里的待办示例保持原文，不绘制为可点击清单。
