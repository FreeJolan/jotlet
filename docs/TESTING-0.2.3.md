# 0.2.3 测试记录

2026-10-22，修复 Markdown 转换后退格无法取消标题格式的问题。构建为 0.2.3，build 8。

## 修改

编辑器新增段落起始位置的退格处理。刚输入 `# ` 等语法形成的空标题，按一次退格恢复正文；有文字的标题在行首退格，也先取消标题格式，保留文字和前一段的换行。标题中的链接和斜体等行内属性保留。

项目列表、编号列表、待办和引用在前缀处退格，先退一级或退出该格式。退出已完成的待办时同步清除完成状态的显示装饰。空段落里残留的加粗、斜体、等宽、下划线、删除线和链接格式也能用退格清除。

取消格式支持撤销与重做，包括没有任何字符、只有输入格式的空标题。光标在文字中间、选中文字或输入法正在组合文字时，继续交给原生编辑器处理删除。正文在行首退格仍可合并上一行。
